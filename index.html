Use the agent

Your computer. Your accounts.

1

Install the prerequisites

Node 22.23.1 or newer, Codex CLI and your own ChatGPT, Walrus Memory and Tatum Free access.

2

Extract and open Terminal here

bash start.command --live "$HOME/.local/share/recall-agent"

Complete official Walrus sign-in and the private Tatum setup. The conversation starts empty.

3

Ask your own question

Provide selected Sui transaction IDs. Ask about gas, balance changes, stored observations or the original CSV.

Choose your model

The launcher checks your available ChatGPT models before provider activation and passes the selected model explicitly on each launch. The verified run used gpt-5.6-luna; the tools do not require that particular model. The tool interface is MCP; other clients require separate configuration and validation.

Request limits persist across new chats, with no session expiry. Use your own included quota and sponsored access, with no paid fallback.
