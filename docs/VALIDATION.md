Tests use installed SDKs with synthetic transports; they make no model or provider request. Checks cover exact amount normalization, unknown/failed/complex transactions, gas, scope, correction dates/forks, paging/revisions/coverage, unknown write outcomes, idempotency, durable limits, billing freshness, original-key continuation, configuration restoration and CSV escaping.

The website build copies the exact evidence bytes into a new external output directory. Browser QA verifies desktop/mobile layout, receipt display and clipboard feedback. A static evidence page is not a live provider call.
